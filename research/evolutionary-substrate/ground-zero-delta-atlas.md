# Ground-Zero Delta Atlas — executable design, not launched

This protocol is deliberately staged. It does not reuse V4's rejected
context-free component score and it does not enter market evaluation until the
earlier layers independently pass their gates.

## J1 — construct-only

Inputs: immutable source pins, one read-only authority fixture, declared
parents, fixed seeds, and a list of one-step families/sites.

Outputs: canonical plan, parent/child identity, disposition/reason, exact
delta, deduplication result, and source hashes. Run the production-prior and
coverage-balanced arms from `static-pilot-and-neighborhood-design.md` with an
8,000-attempt total cap.

Gate: every attempt is source/authority/parent bound; no implicit replacement
constructor; no catalog/policy/archive write.

## J2 — synthetic facts and state traces

Inputs: only deterministic, hand-authored fact streams and action/execution
status events. No price series or market-derived fields.

For each admitted reference organism/neighbour, record transition path,
guard truth values, action intents, applied/rejected/canceled/closed outcomes,
state residence, timeout/rearm behavior, and side. Pair a base organism with a
one-step child where possible.

Gate: traces prove a declared semantic distinction and remain deterministic on
two identical runs. A failure is `behavior_unknown` or `static_dead_end`, not a
reason to add a broader simulator.

## J3 — controlled intervention

Predeclare a single intervention family/site and matched parent context. Hold
authority, compiler, synthetic stream, and all unrelated program fields fixed.
Compare only: parent vs one admitted child, and—in a separate lane—two-parent
crossover vs named ordered parents. Report reachability, compile, and synthetic
semantic deltas; do not calculate market/economic outcomes.

Gate: route/site/parent context is complete, edit distance is explicit, and no
component score is emitted. If those conditions fail, return to J1 telemetry.

## J4 — market escalation design only

No market work is authorized by this packet. A future escalation request must
name the frozen authority, source commits, parent/child pairs, predeclared
primary behavioral endpoint, evaluation panel, red-team controls, stopping
rule, archive/selection non-mutation guarantee, and interpretation limits.

The minimum evidence required before requesting J4 is: deterministic J1
coverage, J2 semantic traces, J3 route/site context, and an explicit proof
that the question cannot be answered by static or synthetic evidence.
