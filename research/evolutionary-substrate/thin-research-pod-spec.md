# Thin research pod — design only

## Mission

Measure which existing, authority-bound one-step organism changes can be
constructed and compiled, and which semantic effects appear on deterministic
synthetic traces. The pod must answer reachability and observability questions;
it must not optimize, generate a campaign, alter production policy, or infer
profitability.

## Inputs and outputs

Inputs are a read-only source checkout, a detached engine checkout, immutable
authority/parent fixtures, fixed seeds, and a small predeclared plan list.
Outputs are compact JSONL attempt records, aggregate summaries, deterministic
trace transcripts, command manifests, and checksums under the ignored
AutoResearch `.tmp` tree.

## Responsibilities

- Construct-only driver: invokes an existing sealed constructor; never writes
  to a run/archive/policy location.
- Compile/admission driver: runs existing compiler/validator only.
- Synthetic trace driver: feeds declared synthetic facts/status events only.
- Reducer: classifies no-op, rejected, admitted, and trace-visible changes
  without economic fields.
- Auditor: validates bindings, counts, determinism, and packet checksums.

The pod deliberately has no scheduler, worker fleet, Lab Gateway integration,
Vast dependency, database, service, or learned state. A single local process
is sufficient for a bounded no-market study.

## Stopping rules

Stop and report if: authority binding is ambiguous; a required source seam is
not already implemented; a result would require real market data; any output
would mutate archive/selection/production policy; determinism fails; or the
scope exceeds the predeclared attempt cap. Do not solve those failures by
adding infrastructure.
